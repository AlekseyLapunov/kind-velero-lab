# Ход создания и тестирования решения
## Подготовка стенда

Установлены дополнительные модули ядра и пакет основных плагинов пакетного менеджера DNF:
```bash
dnf update

dnf install kernel-modules-extra

dnf -y install dnf-plugins-core
```

Установлен docker:
```bash
dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

dnf install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

systemctl enable --now docker
```

Установлен kubectl и kind:
```bash
cat <<EOF | sudo tee /etc/yum.repos.d/kubernetes.repo  
[kubernetes]  
name=Kubernetes

mv kind /usr/bin/kind/

chmod +x /usr/bin/kind/kind
```

Установлен helm:
```bash
curl -fsSL -o get_helm.sh https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-4

chmod 700 get_helm.sh

./get_helm.sh
```

```bash

helm repo update
```
## Алгоритм выполнения проекта

Создан кластер и подготовлено пространство имён для приложения:
```bash
kind create cluster --name backup-demo --config kind-config.yaml

kubectl create namespace app
```

Установлено тестовое приложение с PostgreSQL, база заполнена контрольными данными:
```bash
vim postgres-init-config.yaml

vim demoapp.yaml

kubectl apply -f postgres-init-config.yaml

kubectl apply -f demoapp.yaml
```

Развёрнут MinIO на отдельном хосте, ключи вынесены в Secret:
```bash
vim s3-credentials

kubectl create namespace velero

kubectl create secret generic s3-credentials --namespace velero --from-file=cloud=s3-credentials
```

Установлен Velero и настроено сохранение копий в S3-совместимое хранилище (MinIO):
```bash
vim velero-values.yaml

helm install velero vmware-tanzu/velero --namespace velero --create-namespace -f velero-values.yaml

wget https://github.com/velero-io/velero/releases/download/v1.18.2/velero-v1.18.2-linux-amd64.tar.gz

tar xzf velero-v1.18.2-linux-amd64.tar.gz

install -o root -g root -m 0755 velero-v1.18.2-linux-amd64/velero /usr/local/bin/velero
```

Созданы ручная и плановая копии:
```bash
velero backup create demoapp-manual-backup --include-namespaces app --default-volumes-to-fs-backup
```

## Использование сценариев для автоматизации и журналирования действий

### Описание структуры сценариев

Каждый сценарий имеет номерной префикс, отражающий последовательность запуска для проведения тестирования решения:
1. `0_create_backup.sh` - выполняется ручная копия приложения.
2. `1_simulate_crash.sh` - симулируется аварийная ситуация - приложение удаляется.
3. `2_restore.sh` - выполняется восстановление из резервной копии.
4. `3_data_check.sh` - проверяется целостность восстановленных данных.
### Описание алгоритма проверки целостности данных

1. Скрипт `0_create_backup.sh` перед созданием резервной копии проходит по каждой таблице, считая их контрольную MD5-хэшсумму и количество строк. Эти валидационные данные записываются в ConfigMap, который захватывается Velero при создании резервной копии.
2. Скрипт `2_restore.sh` восстанавливает в новом пространстве имён приложение с СУБД из резервной копии, в том числе получает валидационные значения из ConfigMap.
3. Скрипт `3_data_check.sh` использует валидационные значения из ConfigMap и сравнивает с контрольными MD5-хэшсуммами таблиц восстановленной БД. Если результат совпадает с ожидаемыми значениями - целостность данных подтверждена успешно.

## Описание подключения к бакету VK Cloud
1. Создать файл `helm/s3-credentials` на базе файла `heml/s3-credentials.example`:
```ini
[default]
aws_access_key_id = <VK_CLOUD_ACCESS_KEY_ID>
aws_secret_access_key = <VK_CLOUD_SECRET_ACCESS_KEY>
```
2. Создать секрет s3-credentials в пространстве имён Velero:
```
kubectl create secret generic s3-credentials \
  --namespace velero \
  --from-file=cloud=helm/s3-credentials
```
3. Отредактировать файл `helm/velero-values.yaml` и заменить следующие значения:
- `configuration.backupStorageLocation.bucket` - установить имя бакета в VK Cloud;
- `configuration.backupStorageLocation.config.region` - установить `"ru-msk"`;
- `configuration.backupStorageLocation.config.s3ForcePathStyle` - установить `"true"`;
- `configuration.backupStorageLocation.config.s3Url` - установить `"https://hb.vkcloud-storage.ru"`;
3. Сделать апгрейд Helm-релиза:
```
helm upgrade velero vmware-tanzu/velero --namespace velero -f helm/velero-values.yaml
```
